# 研合 科研成果融合

融合多个来源的成果记录，维护归一化词典、候选匹配、身份决策和不可变发布。记录键为 source:id；来源完整快照撤回未出现的记录，部分更新保留它们。在此之上提供可冻结的分数计量：分析选定发布版本、成果类型、年份和词典版本，整计数与分数计数并列，单项贡献始终合计为一。

## 可冻结计量口径

`metrics` 组件从已冻结发布版读取数据，分析过程不依赖可变的当前归一化状态：

- **输入选择**：`metrics.measure` 必须指定发布版，并可固定词典修订版、成果类型、年份区间、计分模式与小数位。输入摘要（含发布版与词典映射指纹）随分析一起持久化。
- **机构归并与未知组**：机构从集群的每个成员记录原始字段提取，按所选词典修订版的别名链归并；缺机构的成员保留在 `unknown`（null）组，不会被丢弃或并入其他机构。
- **两种分数模式**：`equal` 按去重机构均分；`weighted` 要求每个出现的机构（含未知组，用保留键 `unknown`）都给出正整数可核验权重，缺任一权重即拒绝。单项成果在所有机构上的贡献精确合计为一。
- **精确分数与舍入调和**：分数内部用有理数（`Fraction`）保存并以分数形式输出；展示小数按最大余额法舍入，机构行、年份列与总计在舍入后仍然严格一致。
- **整计数并列**：每个汇总格同时给出整计数（联合成果在各机构完整计数，机构间相加可超过成果数）和分数计数（合计等于成果数），两者口径分开呈现。
- **可追溯**：`metrics.drill` 从任一汇总格追到具体成果、成员记录与各自权重；条目身份由成员记录派生，不随主记录集群 ID 变化。
- **冻结不可变**：`metrics.freeze` 只插入不更新，后续发布和词典更新不得改写已交付分析；`metrics.export`/`verify` 支持离线文件核验。
- **发布版对照**：`metrics.compare` 基于共享成员记录、共享外部标识，再到大小写不敏感的折叠标题与类型来匹配成果，绝不只凭主记录 ID 认定同一成果；输出新增、撤回、合并、拆分、重组及标题/类型/年份/机构修订，并给出机构分数变化。

词典的每次变更都写入 `dictionary_history`，可重建任意历史修订版的别名映射（`dictionary.history_snapshot`、`dictionary.resolve_at`），因此旧报表可按旧词典版本复现，且不会被新词典改写。

## 运行环境

使用 Python 3.11，核心功能依赖标准库和 SQLite。演示和测试只使用本地合成数据，不需要账户、设备或外部运行服务。请从项目根目录执行命令。

## 检查与运行

构建检查验证语法，测试使用临时数据目录，不会连接远端服务。

```sh
python3 -m compileall -q researchmesh
python3 -m unittest discover -s tests -v
python3 -m researchmesh demo
```

演示会展示产品的实际数据处理和输出，运行结束自行退出。查看现有接口：

```sh
python3 -m researchmesh --db :memory: describe
```

## 目录与数据

researchmesh/ 保存领域逻辑和请求入口，tests/ 包含正常行为、边界与恢复测试。例子中的标识和记录为合成资料，不包含真实人员或生产测量。业务目录和本地数据库由调用者指定，应与源码分开保存。

## 干净环境复现

容器定义固定运行时版本。构建时准备环境，运行时无需网络；每次启动会复制只读源码到临时工作目录，测试产生的文件不会写回仓库。

```sh
docker build -t local-product-check .
docker run --rm --network none local-product-check
```
